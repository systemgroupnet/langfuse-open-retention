Before you use this

This tool permanently deletes data from your Langfuse instance. Deletion cannot be undone. Read this once, then it will not ask again.

  • It writes directly to ClickHouse by default. It issues ALTER TABLE … DROP PARTITION and ALTER TABLE … DELETE against Langfuse's own tables, bypassing Langfuse entirely. That means it depends on Langfuse's internal schema, which Langfuse is free to change in any release. A Langfuse upgrade could make it delete the wrong thing or fail.
  • It also deletes objects from object storage and rows from Postgres — raw ingestion blobs, media assets, batch exports, audit logs and job history, according to your policy.
  • There is no undo and no recycle bin. Take a ClickHouse, MinIO and Postgres backup before your first live run.
  • It is not affiliated with, endorsed by, or supported by Langfuse. It is an independent tool, provided as-is without warranty of any kind. You use it entirely at your own risk, and you are responsible for any data it removes.

Safer path: leave dry-run mode on (it is, by default), run Preview, and read the report before arming anything. If you would rather not have anything touch ClickHouse directly, switch Policy → Modules → Traces → Deletion method to Langfuse API, which uses only documented endpoints.
